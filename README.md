# 🚀 Task Assignment Backend API

A scalable REST API built with Node.js, Express, and MongoDB featuring authentication and role-based access control (RBAC).

This project was developed as part of a Backend Developer Internship assignment.

---

## 🔥 Features

- User Registration & Login
- Password hashing using bcrypt
- JWT Authentication
- Role-Based Access Control (User vs Admin)
- CRUD APIs for Tasks
- Input validation
- Secure middleware (Helmet, CORS)
- Environment variable configuration
- MongoDB Atlas support
- Production-ready deployment (Render)

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (jsonwebtoken)
- bcrypt
- express-validator
- Helmet
- CORS
- Morgan
